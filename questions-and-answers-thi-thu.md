### Câu P17 (Chương 3, 2 điểm)

A binary classification system is used to detect rotten tomatoes. The confusion matrix shows the following results: Predicted Rotten Predicted Fresh Actual Rotten 45 5 Actual Fresh 8 42 Which ONE of the following sets correctly represents (Accuracy, Recall, Specificity) respectively?

- **a.** 0.85, 0.88, 0.82
- **b.** 0.87, 0.90, 0.84
- **c.** 0.87, 0.85, 0.90
- **d.** 0.90, 0.87, 0.84

> **Đáp án hiện tại trong code: B** — LO: AI-3.3.1 — K3 (2 điểm)
**Giải thích hiện tại:**
- **EXPLANATION:** Accuracy = (True Positives + True Negatives) / Total = (45 + 42) / 100 = 0.87. Recall = True Positives / (True Positives + False Negatives) = 45 / (45 + 5) = 0.90. Specificity = True Negatives / (True Negatives + False Positives) = 42 / (42 + 8) = 0.84.
